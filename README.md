# Team Task Management System

## Project Overview
The Team Task Management System is a collaborative project developed to demonstrate GitHub team workflows, branch management, pull requests, and documentation practices.

## Objectives
- Maintain project code using GitHub repositories.
- Use feature branches for independent development.
- Collaborate using Pull Requests.
- Review and merge changes into the main branch.
- Maintain project documentation using README.md.

## Project Features
- Task creation and management
- Task status tracking
- Team collaboration
- Branch-based development
- Pull Request workflow

## Team Workflow
1. Create a feature branch from `main`.
2. Develop and update project files in the feature branch.
3. Commit changes.
4. Create a Pull Request.
5. Review the changes.
6. Merge the Pull Request into `main`.

## Branches
- `main` – Stable project version.
- `feature-task-management` – Development of task management features.

## Tools Used
- Git
- GitHub
- Markdown

## Conclusion
This project demonstrates collaborative software development using GitHub by implementing branch-based development, Pull Requests, code integration, and README documentation.
